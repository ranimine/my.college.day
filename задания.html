Контрольная точка 2. Мой учебный день

Общая информация

Файлы для работы: template.html (разметка, открывать в редакторе и браузере) и styles.css (стили). Файл styles.css не удалять и не менять — когда вы проставите теги, стили всё оформят автоматически.

Темы контрольной точки: таблицы, списки и формы.

Каркас страницы (шапка, меню, разделы с заголовками, подвал) в template.html уже готов — ваша задача только наполнить разделы тегами по заданиям ниже.

Совет: работайте по одному заданию. После каждого сохраняйте файл (Ctrl+S) и обновляйте страницу в браузере (F5) — сразу увидете результат. Если что-то «сломалось» — смотрите, что изменили последним.

Задание 1. Таблица «Расписание»

В разделе «Расписание» из строк с разделителями «|» сделайте настоящую таблицу.

  1. Таблицу оберните в <table>. Строки — <tr>, ячейки — <td>.
  2. Первую строку (Урок | Время | Предмет) сделайте ячейками-заголовками <th>.
  3. Объединение: в строке «Обеденный перерыв» первая ячейка должна занимать 2 колонки: <td colspan="2">Обеденный перерыв</td>. В этой строке будет всего 2 ячейки, а не 3!

Задание 2. Списки дел и предметов

В разделе «Мои списки» разметьте два списка.

  1. «Дела перед уроками» — маркированный список <ul>, каждый пункт — <li>.
  2. «Топ-3 моих предмета» — нумерованный список <ol>, каждый пункт — <li>.

Задание 3. Анкета

В разделе «Анкета» соберите форму.

  1. Всю анкету оберните в <form action="#" method="post">.
  2. «Имя» — <label> + <input type="text" name="name" required>. Свяжите их: for у label равен id у input.
  3. «E-mail» — то же, но type="email" (проверит наличие @ при отправке).
  4. «Моя группа» — <select name="group"> с тремя <option>: ПИ-101, ИС-202, БИ-303. Первая группа — выбрана по умолчанию (атрибут selected).
  5. «Пара слов о себе» — <textarea name="about" rows="4" placeholder="Напишите пару предложений…"></textarea>.
  6. Две кнопки: <input type="submit" value="Отправить"> и <input type="reset" value="Очистить">.

Задание 4. Мини-опрос: radio и checkbox

В разделе «Мини-опрос» разметьте кнопки выбора вариантов.

  1. Radio: три кнопки <input type="radio" name="route"> — Автобус, Метро, Пешком. name у всех одинаковый, id — разные. Каждую подпишите через <label for="…"> — иначе можно выбрать все три сразу.
  2. Чекбокс «Я согласен(на) на обработку данных» — с атрибутом required, подпись через <label for="…">.
